# File Descriptions

## `P_pacifcus_Beta_tubulin_genes_amino_acid_sequences.xlsx`
Excel file with the amino acid sequence and gene ID corresponding to tree
* Columns:
  * `GENE ID`: one of either `PPA35471`, `ppa_stranded_DN31157_c1_g4_i5`, or `ppa_stranded_DN31157_c1_g1_i5`
  * `Gene name`: clean name
  * `Protein classification`
  * `Amino Acid sequence`: Character string with the Amino Acid sequence of the gene

## `Ppa_ben-1_aln_L-INS-i.fasta`
FASTA file containining the alignmnet of the DNA sequence for the two P.p beta-tubulin orthologs (`ppa_stranded_DN31157_c1_g4_i5`, `PPA35471`).
